# KD ACADEMY — Interior Architecture & Design Portfolio

KD아카데미 인테리어 건축 디자인 전문 포트폴리오 웹사이트 프로젝트입니다.

* **공식 제작 지침서**: [`PROJECT_GUIDELINE.md`](./PROJECT_GUIDELINE.md)를 참조하세요.
* **실행 방법**:
  - 탐색기에서 `index.html` 파일을 더블클릭하여 바로 열 수 있습니다.
  - 또는 로컬 서버: `python -m http.server 3000` 실행 후 브라우저에서 `http://localhost:3000` 접속
* **현재 상태**: 3단계(디자인 시스템: 산세리프 + 2D CAD 도면 투과 호버) 완료, 4단계(갤러리 & 콘텐츠 디테일 강화) 준비 중.
